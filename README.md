# Monthly Productivity

A group-reviewed monthly planning application engineered for high-accountability goal setting and execution.
Built with a modular NestJS API, Supabase PostgreSQL, and an Android-first Expo React Native mobile client.
Work is organized in monthly cycles following strict three-record immutability and transparent peer reviews.

## Commands

```bash
pnpm install
pnpm lint
pnpm typecheck
pnpm test
```
