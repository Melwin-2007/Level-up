# Security Review — Milestone 1

This document reviews every route in the Milestone 1 API against the checklist in [docs/SECURITY.md](file:///e:/Level-up/docs/SECURITY.md) Section 5:

1. Identity from validated JWT (`sub`) only.
2. Resource loaded by ID AND scoped through the caller (membership or ownership) in the same query where possible; non-members always receive 404 (DECISION 20).
3. Cycle state checked via `CycleStateService` where applicable.
4. Zod validation including UUID path parameters and max lengths on text fields.
5. Automated test proves unauthenticated calls (401), non-member calls (404), and unauthorized role calls (403) are denied.
6. Response contains only allowed fields via explicit response mappers; no raw Prisma rows returned.

## Operational Safeguards Verified

- **No Secrets Leaked**: Log files and responses contain no tokens, passwords, database credentials, or private availability/constraints.
- **Log Sanitation**: `httpLoggerMiddleware` logs only metadata (`requestId`, `userId`, `method`, `route`, `statusCode`, `durationMs`). No request/response bodies or goal/comment text are logged.
- **Header Protection**: Helmet is enabled globally on the Express application; CORS is enabled; `x-request-id` header is attached to every request and preserved on errors via `HttpExceptionFilter`.
- **Dynamic Route Coverage**: Dynamic route extraction from Nest's router verified via `test/security/auth-fuzz.e2e-spec.ts`.
